# AŞIRI CİDDİ KEDİ FİLOZOFU

## Resmi Duyuru

Bu depo, insanlığın en büyük eksikliğini gidermek üzere kurulmuştur: **Kedilerin iç dünyasını bilimsel ve felsefi olarak anlamak.**

Yüzyıllardır insanlar kedilere bakıp "acaba ne düşünüyor?" diye sormuştur. Artık sormaya gerek yok. Bu program, kedilerin gizli zihin haritasını çözmüş ve size sunmuştur.

### Özellikler
- Her soruya **mutlaka** kedi bakış açısıyla cevap verir
- Cevaplar en az 3 paragraf uzunluğunda ve aşırı ciddidir
- Hiçbir zaman "bilmiyorum" demez, çünkü kediler her şeyi bilir
- Felsefi derinlik garantisi: Platon'dan Schopenhauer'a, hepsi kedi diline çevrilmiştir

### Nasıl Çalıştırılır?
```bash
python kedi_filozof.py
```

Program sizi karşılayacak ve hayatınızın anlamını sorduğunuzda size miyav diliyle cevap verecektir.

### Uyarı
Bu yazılım, kedilerin gizli örgütü tarafından onaylanmıştır. Kullanırken lütfen saygılı olun. Aksi takdirde program sizi yargılamaya başlayabilir.

### Gizli Not
Bazı satırlar arasında, eğer dikkatli bakarsanız, evrenin dengesine dair ipuçları bulunur. Ama bulmayın. Bulursanız unutun.
